# 모바일 PC 설치 안내 (2026-11-06)

사용자가 Google Play 승인 완료를 알린 뒤 양 앱에 PC 설치 안내 추가를 지시했다. 설정의 기존 지원/정보 그룹에서 오프라인 안내로 진입한다. 앱 버전·스토어 제출·전송 엔진은 이번 변경에 포함하지 않는다.

## 화면 계획과 검토

- 기존 iOS 시스템 글꼴·그룹 폼·ultraThinMaterial·청색 계열 `#24466B` 배경 색조를 재사용한다. Android는 기존 시스템 글꼴·Settings 행·기본 대화상자·시스템 밝기별 본문/보조 색을 사용한다. 새로운 색상이나 장식을 추가하지 않는다.
- 흐름은 `설정 → 컴퓨터에 FTA 설치하기 → Windows/macOS 설명과 주소 복사 → Linux 지원 준비 중 표시 → 같은 LAN 및 최초 승인 안내`다. 설명과 주소는 좌측 정렬하고 스크롤하며, OS별 고정 순서로 구분한다.
- 검토 결과 기존 앱의 기본 컨트롤과 소재를 그대로 쓰는 구성이 이번 요청에 적합하다. 전송 메인 화면·기록·기기 아이콘·신뢰 설정의 변경은 필요하지 않다.

## 배포 경로와 정책 검토

GitHub API로 확인한 `v0.1.2` 자산은 Windows x64 설치 프로그램, Apple Silicon Mac DMG, 각 빌드 정보와 해시다. 따라서 안내는 해당 데스크톱 전용 릴리즈에 고정하고, 새 PC 릴리즈를 검증할 때 양 플랫폼의 주소 상수를 갱신한다. Intel Mac과 Linux 설치 파일이 있다고 안내하지 않는다. Linux는 실기 미검증이므로 ‘지원 준비 중’으로 표시하고 소스 주소와 복사 버튼을 제공하지 않는다.

- 릴리즈 주소: <https://github.com/froiibn/FTA/releases/tag/v0.1.2>

2026-11-06 [Apple 2.5.2](https://developer.apple.com/app-store/review/guidelines/#software-requirements), [Google Device and Network Abuse](https://support.google.com/googleplay/android-developer/answer/16559646), [Google 외부 콘텐츠 링크 프로그램](https://support.google.com/googleplay/android-developer/answer/16470497)을 재확인했다. Apple은 앱 기능을 바꾸는 코드 다운로드/실행을 제한하고 Google은 외부 실행 코드·자체 업데이트 및 외부 앱 링크에 별도 규칙을 둔다. PC 동반 앱 안내에 대한 포괄적인 면제는 확인하지 못했다. 이번 구현은 네이티브 설명과 사용자 요청에 따른 주소 복사만 제공하며 모바일에서 브라우저를 열거나 설치 파일을 다운로드/설치/실행하지 않는 방식으로 판단해 적용했다. 이는 개별 스토어 심사 승인을 보장한다는 의미가 아니다.

## 최초 안내 구현 검증 (Linux 표시 정정 전)

검사와 캡처는 사용자 소유 Mac의 `output/pc-install-guide`에 저장한다. 양 앱 10개 언어 카탈로그와 생성 리소스의 키·형식·동기화를 검사한다. 실제 전송이나 상대 OS 설치를 이번 안내 화면 검사로 대체하지 않는다.

- iOS 시뮬레이터 Debug 빌드 성공. 한국어/영어의 설정 진입·안내·복사 확인·Linux 주소 접근·복귀 테스트를 밝은/어두운 외관에서 각각 실행해 모두 통과했다. `simctl pbpaste`로 릴리즈 주소의 정확한 복사도 확인했다. 캡처 8개를 추출해 두 외관을 시각 검토했다.
- Android Debug APK 빌드와 lint 성공. lint는 오류 0개·경고 19개다. API 37 전용 에뮬레이터에 업데이트 설치하고 한국어 밝은 화면, 영어 어두운 화면, 독일어 1.5배 글자에서 안내 진입·복사 버튼·Linux/연결 안내까지 스크롤·닫기를 확인했다. 검사 후 전용 에뮬레이터의 글자 크기·외관·앱 언어는 기본 검사 상태로 복구했다.
- iOS 145개·Android 147개 문자열의 10개 언어 리소스 검사가 통과했다. `git diff --check`도 통과했다. Rust/데스크톱 동작은 변경하지 않아 해당 빌드·전송 시험은 재실행하지 않았다.
- 실기 설치·실기 UI, Windows/macOS/Linux 신규 설치, 이번 변경의 스토어 업로드/심사 제출은 수행하지 않았다. 기존 승인 버전과 빌드 번호를 유지한다.

## Linux 표시 정정

사용자가 Linux 실기 미검증을 확인한 뒤 변경을 지시했다. 양 앱 10개 언어에서 Linux를 ‘지원 준비 중’으로 표시하고 소스 안내·주소·복사 버튼 및 전용 상수를 제거했다. Windows/macOS 안내와 주소 복사는 유지한다. Linux 실기 시험이 끝난 뒤 실제 지원 범위와 설치 경로를 다시 확정한다.

정정 후 iOS 시뮬레이터 Debug 빌드·Android Debug APK 빌드·양 앱 10개 언어 생성 리소스 검사·`git diff --check`가 통과했다. 소스 빌드 안내와 Linux URL이 앱 코드/카탈로그에 남지 않았음을 검색으로 확인했다. 이번 문구/버튼 제거 후 UI 자동 검사는 재실행하지 않았고 실기 설치·스토어 업로드도 수행하지 않았다.
