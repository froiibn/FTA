# FTA 0.1.6

- 새 블랙·네이비 앱 아이콘을 Mac, Windows, iOS, Android 소스에 적용했습니다.
- 데스크톱에서 접힌 창을 화면 가장자리에서 펼치면 현재 모니터의 사용 가능 영역 안에 맞춥니다.
- 파일 저장 완료가 확인되면 전송 진행 바가 100%로 표시되고 3초 뒤 사라집니다.
- Mac 전송 기록 상세창은 왼쪽 위의 빨간 닫기 버튼을 사용합니다. Windows 상세창은 오른쪽 위의 닫기 버튼을 사용합니다.
- iOS와 Android의 PC 설치 안내는 플랫폼별 업데이트 JSON에서 설치 파일 주소를 가져옵니다.

Mac 설치 파일은 Apple Silicon용 `FTA_0.1.6_aarch64.dmg`입니다. 자동 업데이트가 설정된 Mac에서는 앱에서 업데이트할 수 있습니다. Windows 설치 파일은 Windows에서 빌드·검증한 뒤 이 릴리스에 추가합니다. 모바일 앱 변경은 별도 스토어 업데이트에 포함됩니다.
