# FTA 0.1.5

Windows·macOS 공통 앱에 GitHub Releases 기반 자동 업데이트를 추가한다. 시작 후·6시간 간격 확인, 새 버전 네이티브 확인, 다운로드·버전 결합 서명 검증, 설치·재시작을 제공한다. 설정의 앱 동작에서 확인 아이콘으로 재확인할 수 있다. 기존 디자인과 전송 신뢰 정책은 유지한다.

진행 중 네트워크 작업이나 미완료 전송이 있으면 설치를 보류한다. 별도 CLI/MCP 엔진을 종료하거나 설정·등록·수신 파일을 삭제하지 않는다. [PC 자동 업데이트](../desktop-updates.md).

**0.1.4 이하 사용자는 0.1.5 설치 파일을 한 번 직접 설치해야 한다.** 이전 버전에 업데이트 코드가 없어 이번 릴리스로 자동 이동할 수 없다. 이후 릴리스부터 새 경로를 사용한다.

## 배포 범위

Mac Apple Silicon DMG와 updater 앱 아카이브를 사용자 Mac에서 로컬 빌드·Developer ID 서명·Apple 공증·검증하여 게시한다. 개인키를 공개하지 않고 공개 키·서명만 제공한다. 공식 updater를 포함한 의존성의 원문 라이선스·저작권 고지도 설치 번들에 동봉한다. 로컬 검사·공증·서명·업로드·다운로드 대조를 자동화했으며 GitHub Actions는 사용하지 않는다.

Windows 공통 기능과 perMachine NSIS 빌드 절차를 포함한다. Windows 설치 파일은 사용자 Windows PC의 네이티브 빌드·검증 후 같은 릴리스에 추가해야 한다. Mac에서 Windows 설치/UAC/재시작 검증이나 설치 파일 배포를 완료한 것으로 보고하지 않는다. Intel Mac·Linux·모바일 스토어 변경은 이번 범위에 없다.

기존 태그·릴리스는 유지한다. 최종 해시·소스 커밋·공증과 실제 검사 범위는 플랫폼별 build-info·SHA256SUMS에 제공한다.

## 확인된 배포 결과

[Mac 0.1.5 릴리스](https://github.com/froiibn/FTA/releases/tag/v0.1.5)는 공개 상태이며 소스 태그는 `778376bd6bb61b277fdbdf4eb196c694cb234f5e`다. Apple 공증은 Accepted(제출 ID `294a621f-147d-4363-a593-92d759bfcd2f`)이며 앱·DMG 티켓, Gatekeeper·DMG 무결성 검사가 통과했다. 최종 updater 아카이브에서도 앱 티켓과 Gatekeeper 승인을 다시 확인했다.

사용자 Mac에서 headless 테스트 85개(조건부 ignored 1개), desktop 일반 테스트 12개, fmt·Clippy·desktop check·TypeScript/Vite 및 기록/토스트 회귀 15개가 통과했다. 최종 파일의 정상 서명·바이트 변조·서명 버전 변조 검사와 공개 GitHub feed/패키지 다운로드·공식 Mac 설치기의 임시 앱 교체 검사도 각각 통과했다. 후자는 개인 Applications 앱을 실행/교체하지 않고 엔진/MCP·라이선스 고지·codesign·외부 테스트 데이터 보존을 확인했다.

Mac/Windows 스타일의 설정 기본/최소 크기 4개 캡처를 검토했으며 가로 넘침·업데이트 상태/버튼 겹침은 없었다. Windows 스타일 브라우저 검사가 Windows 네이티브 실행·설치 검증을 뜻하지 않는다.

- DMG SHA-256: `162022d9303317c8ab0dee2479b38d27ad75d9d4da775e124e18522450183463`
- Updater archive SHA-256: `cacf1b44f6e17da267de280a7ec3d101559589cfe02ab516463a5a7b3062435a`
- 공개 자산: DMG·updater archive·서명·타깃별 feed·SHA256SUMS·빌드 정보, 6개. 모두 draft에서 재다운로드해 해시를 대조한 뒤 공개했다.

**Windows 설치 파일·Windows updater feed는 아직 게시하지 않았다.** 이 Mac에 Windows 실행 환경이 없어 해당 PC의 네이티브 빌드·설치/UAC·재시작 검증이 남아 있다. Windows 담당자는 `v0.1.5` 태그로 빌드하고 검증한 NSIS·build-info를 게시 Mac에 전달해 같은 릴리스에 추가한다. 공개 Mac 파일과 기존 태그는 덮어쓰지 않는다.
