# FTA 0.1.3

## 변경 사항

- Windows·macOS 및 모바일의 주요 동작 버튼을 접근성 이름을 가진 아이콘으로 표시한다.
- 데스크톱 수신 내용은 크기 조절 가능한 독립 창에서 열며, 같은 기록의 창은 재사용한다.
- 데스크톱 기록창은 기기 검색 성공과 독립적으로 저장된 목록을 먼저 불러오고 재활성화 시 갱신한다.
- iPhone·Android 소스에는 PC 설치 안내, 수신 배너·읽지 않은 기록 표시·시스템 알림 보완, 이미지 미리보기와 개별 제거를 제공하는 첨부 목록 개선을 포함한다.
- 최초 수신자 한 번 승인, 등록된 온라인 기기에만 전송, 수신 최종 저장 확인 정책을 유지한다. 자동 업데이트는 구현하지 않았다.

## 배포 순서와 검증 경계

사용자 지시에 따라 Mac Apple Silicon용 0.1.3 DMG를 먼저 배포한다. 로컬 Developer ID 서명·Apple 공증·티켓 첨부 후 서명, Gatekeeper, DMG 무결성과 동봉 파일을 확인한다. 해시·소스 커밋·검증 결과는 `build-info-macos-0.1.3.json`과 `SHA256SUMS-macos-0.1.3.txt`에 게시한다. 기존 릴리스는 보존한다.

Windows는 사용자가 별도 에이전트에게 같은 `v0.1.3` 태그의 로컬 빌드를 지시한다. Windows 설치 파일과 해시·빌드 정보는 기존 Mac 자산을 바꾸지 않고 이 릴리스에 추가한다. Mac에서 Windows 검증을 수행한 것으로 보고하지 않는다. Intel Mac·Linux 설치 파일은 이번 배포 범위에 없다.

iPhone·Google Play는 후속 별도 배포다. 이번 소스 푸시가 모바일 스토어 업데이트를 의미하지 않으며 모바일 버전·빌드 번호는 해당 배포 시 갱신한다. 모바일 PC 안내 주소는 Windows 후속 설치 파일까지 확인한 뒤 새 릴리스로 갱신한다. GitHub Actions와 사용자 MCP 클라이언트 설정은 변경하지 않는다.

## Mac 로컬 검증 결과

- workspace 포맷 검사, 기본 테스트 83개(의도된 ignored 1개), Clippy 통과.
- 데스크톱 check·테스트 11개·Clippy, 기록 조회 회귀 검사 4개, TypeScript/Vite 빌드 통과.
- 실제 Rust 엔진 간 TLS 텍스트·URL·25개 파일 최종 저장과 파일 바이트 일치 확인. 같은 소스의 별도 식별자 검증 앱에서 기록 최초 열기·닫고 재열기의 자동 표시 및 아이콘 버튼을 가진 독립 수신창 확인.
- Developer ID 서명, 실행 파일 Hardened Runtime·타임스탬프, Apple 공증 Accepted, DMG 티켓 첨부·검증, 앱·DMG Gatekeeper, DMG 무결성과 마운트한 앱의 전체 파일·링크 일치 확인.
- 다른 Mac의 설치 및 실기 LAN 전송, Windows·Intel Mac·Linux 실행은 이번 Mac 배포에서 검증하지 않았다.
