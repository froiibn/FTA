# FTA 모바일 0.1.4 배포 기록

2026-11-06 사용자 Mac에서 로컬 빌드했다. 데스크톱 `v0.1.4` 태그는 유지하며 GitHub Actions를 사용하지 않는다. 이 문서는 모바일 업데이트를 별도로 추적하기 위해 추가했다.

## 변경 범위

- Windows·macOS PC 설치 안내와 Linux 지원 준비 상태.
- 아이콘 중심 동작 버튼과 현지화된 접근성 이름.
- 수신 배너·햅틱·기록 미확인 수·OS 알림. 최종 수신 이벤트를 기준으로 하며 권한과 사용자의 알림 차단 설정을 존중한다.
- 첨부파일 미리보기·이름·크기·형식, 개별 제거·전체 비우기·전송 아이콘.

기존 신뢰·프로토콜 정책을 유지한다. iOS의 백그라운드/잠금 중 수신 제한과 Android의 foreground Service를 구분한다. PC 링크는 Windows 설치 파일도 제공하는 기존 공개 릴리스 경로를 유지한다.

## 로컬 검증

- iOS 0.1.4 (11): Release archive와 Apple Distribution export 성공. 서명·프로파일·개인정보 매니페스트·10개 언어·법률 고지의 엄격한 배포 검증 통과.
- iPhone·iPad·Duo 전용 새 시뮬레이터에서 실제 앱의 현지화 화면 검사 통과. 앱 UI나 가짜 온라인 기기를 주입하지 않고 실제 캡처로 90개 홍보 이미지를 제작했다.
- Android 0.1.4 (9): 서명 AAB/APK 빌드, 업로드 인증서 일치, API 29/37, ARM64·16KB ELF/ZIP 정렬, 테스트 코드 제외·고지·149개 문자열과 10개 언어 검증 통과.
- Android 회귀 검사 48개와 백그라운드 검사 37개 통과. 에뮬레이터와 Mac 사이 실제 TLS 전송, 최초 수신 등록 승인, 최종 저장·정확한 바이트, 양방향 32MiB·텍스트·URL, Home·화면 꺼짐·재생성·Wi-Fi·명시적 중지를 확인했다.
- 이번 업데이트를 실제 iPhone/Galaxy에 설치해 검사하지 않았다. 원어민 검토·최소 지원 OS 전체 검증을 했다고 주장하지 않는다.

증빙 디렉터리는 `output/mobile-store-0.1.4/`다. 기존 테스트 데이터가 있는 개인 기기를 지우지 않고 전용 시뮬레이터/에뮬레이터만 사용했다.

## 스토어 상태

### Android

[제출 2](https://play.google.com/console/u/1/developers/6290721239636852370/app/4973686468229683954/publishing/submission-activity/2/details)는 0.1.4 (9) 프로덕션 빌드와 10개 언어 × 3개 폼 팩터 스크린샷 변경, 총 31개 변경사항이다. 2026-11-06 제출 후 재접속한 제출 활동에서 검토 접수를 확인했고, Xcode 인증 해결 후 다시 조회한 제출 2의 상태는 **출시됨**이다. Play Console은 2026-11-06 오전 6:01 출시와 앱 업데이트 게시 알림을 표시했다. 기존 대상 178개 국가/지역, 출시율 100%, 관리형 게시 사용 중지로 승인 후 자동 공개한다. 이는 Play Console에서 확인한 출시 상태이며 모든 지역·기기의 캐시 전파 완료나 실제 사용자 업데이트 설치를 검증한 것은 아니다.

네이티브 디버그 심볼 ZIP이 연결됐다. 유일한 경고는 R8/ProGuard 가독화 파일 미첨부 안내이며 이 빌드는 난독화를 사용하지 않는다. 기존 아이콘·피처 그래픽·설명과 소유자가 선택한 AI 라벨 지정 안 함을 유지했다. 실제 전용 에뮬레이터의 휴대전화·태블릿 캡처로 120개 슬롯 참조를 교체했다. 7/10인치 슬롯은 같은 태블릿 이미지이며 Google 중복 제거에 따라 tablet7 파일명을 공통 참조한다.

### iOS

[iOS 심사 제출](https://appstoreconnect.apple.com/apps/6828538463/distribution/reviewsubmissions/details/7c992f3b-cfe2-4261-9a01-0d46733f4143)은 **심사 대기 중**이다. 10개 언어 업데이트 설명·프로모션 문구, iPhone·iPad·Duo 각 3장(총 90장)을 저장했다. 언어별 화면을 다시 열어 이미지 파일명과 업데이트 설명을 대조했다. 중형 iPhone의 직접 업로드 0은 대형 iPhone 이미지 상속이며 누락이 아니다. 승인 후 자동 출시·전체 사용자 즉시 업데이트·기존 평점 유지를 설정했다.

빌드 11은 로컬 archive/export·배포 검증 후 소유자의 Xcode 재로그인으로 Organizer의 **FTA 0.1.4 (11) uploaded** 완료를 확인했다. TestFlight에서 Apple 처리 후 **제출 준비 완료**로 변경됐으며 수출 규정 문서 누락은 표시되지 않았다. 기존 소유자 결정 `ITSAppUsesNonExemptEncryption=false`를 유지했다.

빌드 11을 0.1.4에 연결·저장하고 새로고침 후 연결 유지와 자동 출시·전체 사용자 즉시 업데이트·기존 평점 유지를 재검증했다. Add for Review로 제출 준비 항목 0.1.4 (11) 하나를 확인한 뒤 실제 **심사를 위해 제출**을 실행했다. 제출 ID `7c992f3b-cfe2-4261-9a01-0d46733f4143`, 제출 시각 2026-11-06 오후 10:59, **1개 항목 제출됨 / 심사 대기 중**을 확인하고 제출 상세를 새로 열어 상태를 재검증했다. 아직 iOS 승인·공개 출시는 아니다.

이전 Xcode 계정 접근 오류·Mac 잠금과 웹 세션 만료는 소유자의 잠금 해제 및 재로그인으로 해소됐다. 인증서 재발급·개인키 추출·기존 공개 버전 변경은 하지 않았다.

업로드·심사 제출·승인·공개 출시는 각각 구분한다. 위 상태는 마지막 UI 재조회 기준이다. iOS는 Apple 심사 결과를 기다리고 Android는 Play Console에서 출시를 확인했다.
