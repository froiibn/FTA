# FTA 0.1.4

## 변경 사항

- 데스크톱 상단의 고정 안내·오류 배너를 제거하고 모든 창의 일시적 결과를 1초 하단 토스트로 통합한다. 같은 주기 조회 오류는 복구 전까지 반복하지 않는다.
- 파일 전송이 끝난 뒤 진행 문구·진행 바가 남지 않게 한다. 최종 결과는 토스트와 저장된 기록에서 확인한다.
- 작은 전송창은 기존 크기·디자인을 유지하고 본문 내부 스크롤로 첨부 동작 버튼과 메시지 입력창에 접근할 수 있게 한다.
- 긴 기록 제목·기기명은 텍스트 영역 안에서 줄바꿈하여 상태·삭제 버튼을 침범하지 않게 한다.
- 등록 기기명은 줄바꿈하고 등록 해제 버튼의 크기와 접근성을 유지한다.
- 접힌 44×44 위젯에서는 토스트를 숨기고 타이머를 해제한다. 펼칠 때 지난 토스트를 재표시하지 않는다.

## 배포와 검증

Mac Apple Silicon용 DMG를 사용자 Mac에서 로컬 빌드하여 Developer ID 서명·Apple 공증·티켓을 적용한다. 실제 서명·Gatekeeper·디스크 이미지 무결성·마운트한 앱 일치 검사, 소스 커밋과 해시는 릴리스의 `build-info-macos-0.1.4.json`·`SHA256SUMS-macos-0.1.4.txt`에 게시한다. 기존 0.1.3 태그·배포 파일은 유지한다.

화면 수정은 같은 소스의 별도 식별자 Mac 네이티브 앱에서 실제 파일 선택·본문 스크롤, 긴 TLS 수신 기록·등록 기기명, 접힌 상태에서 실제 엔진 연결 실패 후 펼침까지 확인했다. Mac·Windows CSS의 기본/최소 크기 16개와 접힘 2개 경우, 기록/토스트 회귀 15개를 검증했다. 자세한 범위는 [검증 계획](../verification-plan.md)을 따른다.

Windows는 사용자가 별도 에이전트에게 `v0.1.4` 태그의 로컬 빌드를 지시한다. Windows 설치 파일·해시·빌드 정보는 같은 릴리스에 추가하며 Mac 자산은 유지한다. Mac에서 Windows 네이티브 검증을 수행한 것으로 보고하지 않는다. Intel Mac·Linux 설치 파일과 모바일 스토어 업데이트는 이번 배포 범위에 없다. GitHub Actions와 사용자 MCP 클라이언트 설정은 변경하지 않는다.

0.1.4 버전 반영 후 사용자 Mac에서 workspace fmt·기본 테스트 83개(의도된 ignored 1개)·Clippy, 데스크톱 check·테스트 11개·Clippy, 기록/토스트 회귀 15개, TypeScript/Vite 빌드 및 엔진·MCP·데스크톱 release 패키징이 통과했다. 앱/동봉 실행 파일/DMG의 Developer ID 서명, 실행 파일 Hardened Runtime·타임스탬프와 앱·Cargo·npm·Tauri 버전 일치도 확인했다.

Apple 공증은 `Accepted`이며 DMG 티켓 첨부·검증, 앱/DMG Gatekeeper, DMG 무결성과 읽기 전용 마운트에서 동봉 앱의 전체 파일·링크 일치를 확인했다. 공증 제출 ID와 최종 티켓 첨부 후 해시는 배포 빌드 정보에 기록한다. 다른 Mac에서의 설치·실기 LAN 전송은 이번 패키지 검증에서 수행하지 않았다.
