# FTA 0.1.2 사전 릴리스

- 전송 목록은 현재 연결 가능한 기기만 표시하며 오프라인 등록은 설정 관리에 보존한다.
- 같은 ID의 새 주소는 pin 인증 후 갱신한다. 이름만 같은 새 ID를 자동 신뢰하거나 합치지 않는다.
- mDNS goodbye 없는 단절도 다음 접속 확인에서 제외한다.
- PC는 iOS·Android 기기를 휴대폰 아이콘으로 표시한다.
- 기존 Mac Glass·Windows 전용 스타일과 최초 수신자 한 번의 등록 승인 정책을 유지한다.
- iOS 네이티브 초안 소스도 포함한다. iOS 설치 파일은 이번 PC 릴리스에 배포하지 않는다.

## 배포 범위

Mac Apple Silicon용 DMG·플랫폼별 SHA-256·빌드 정보를 게시한다. Mac에서 Windows 설치 파일을 만들지 않으며 Windows 검증은 후속 담당자가 수행한다. Windows는 [같은 태그의 로컬 빌드 절차](../../packaging/windows/README.md)를 따른다. 사용자 MCP 설정과 GitHub Actions는 변경하지 않는다.

새 Mac 파일은 Developer ID 서명을 적용하되 공증 인증 정보가 현재 키체인에 없어 공증은 미수행이다. 공증 완료나 Gatekeeper 통과로 표시하지 않고 사전 릴리스로 게시한다. 기존 공증 완료 0.1.1 파일·태그는 유지한다. 실제 이번 빌드의 검증 결과·서명·해시·공개 소스 커밋은 릴리스의 `build-info-macos-0.1.2.json`에 기록한다.
