# FTA Android connected-device service demonstration

This public review aid was approved for publication by the app owner.
It shows two actual Android emulators using LAN discovery, recipient registration
approval, and completed reception while the receiving app is at Home. Only
synthetic demonstration content is used.

[Play or download the 66-second demonstration](https://raw.githubusercontent.com/froiibn/FTA/main/docs/android-review/connected-device-review.mp4)

The app uses the connectedDevice foreground service with an ongoing notification
and a user Stop action. The recording does not demonstrate every device maker’s
screen-off policy, OS restriction bypass, or actual Google Play approval.
