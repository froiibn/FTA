# 초기 집 네트워크 설정

사용자가 Windows·macOS 모두 앱에서 초기 연결 설정을 지원하도록 요청했다. 기존 수동 주소 입력과 OS 방화벽 설정을 설정 창의 ‘집 네트워크 연결’로 보완한다. 빌드·검증은 사용자 소유의 해당 OS 컴퓨터에서만 수행하며 GitHub Actions는 사용하지 않는다.

## 화면 계획과 검토

기존 팔레트 surface #171b20, paper #1e242b, ink #e3e9ef, muted #9ba9b8, accent #88add2, line #343d48과 시스템 글꼴을 유지한다. 작은 전송 본체는 바꾸지 않고 별도 설정 창에 한 영역만 추가한다.

제목·재점검 → 현재 상태 → 실제 연결 선택 → 적용 주소·대역 → 집 연결 확인 → OS별 변경 선택 → 저장 순서다. 왼쪽 정렬과 기존 설정 행 간격을 사용한다. 검토 결과, 방화벽과 로컬 네트워크 권한을 하나의 ‘정상’ 표시로 합치면 오판할 수 있어 각각의 결과·한계를 표시한다. 가짜 연결 상태는 추가하지 않는다.

## 공통 경계

- 현재 OS 연결을 사용자가 ‘신뢰하는 네트워크’로 확인해야 저장할 수 있다. 체크·해제와 선택한 연결은 사용자별 화면 설정으로 즉시 기억하고 재점검·설정 창 재생성·앱 재실행 후 같은 연결 정보에만 복원한다. 플랫폼·OS 연결 ID·주소·prefix·대역이 다른 연결에는 이어붙이지 않는다. 이 기억은 OS 권한 적용 결과가 아니며 저장 시 기존 native TTL·연결 재조회·범위 검증을 그대로 수행한다. 사설 주소라는 이유만으로 집이라고 신뢰하지 않는다. 간편 설정 후보는 활성 사설 IPv4이며 IPv6·특수 네트워크는 기존 수동 입력을 사용한다.
- UI는 연결 ID·주소와 변경 선택만 제출한다. 실행 파일·CIDR·명령은 제출하지 않는다. Rust가 현재 인터페이스를 재확인하고 대역을 산출한다. 엔진 경로는 호스트의 배포 경로에서 얻는다.
- OS 변경 후 재조회하고 확인된 경우에만 엔진 수신 주소·허용 대역·자동 발견 설정을 저장한다. 기존 포트는 유지한다. 변경·거절·취소·실패를 성공으로 표시하지 않고 실패 후에도 재점검한다. OS 변경 후 앱 설정 저장이 실패하면 일부 적용 가능성을 안내한다.
- 전송을 갑자기 끊지 않도록 서비스 재시작은 별도 사용자 동작이다. 설정 저장은 연결 검증 완료가 아니다. 재시작 후 엔진 상태와 실제 등록 기기 접속을 확인한다.
- 권한 변경은 설정 창에서만 호출한다. 파일 전송·MCP 경계는 바꾸지 않는다.

## macOS

Windows의 공용·개인 프로필을 적용하지 않는다. Application Firewall의 활성·전체 수신 차단·엔진 차단을 읽고 미확인 결과를 허용으로 추정하지 않는다. 방화벽이 꺼져 있으면 유지하며 불필요한 규칙 추가를 생략한다. 전체 수신 차단이 켜져 있거나 확인되지 않으면 해제하지 않고 시스템 설정으로 안내한다.

필요한 엔진 허용만 OS 관리자 인증을 사용하는 고정 AppleScript의 `socketfilterfw --add/--unblockapp`로 요청한다. 엔진은 별도 인자로 전달하고 `quoted form`으로 인용한다. 다른 앱·전역 방화벽·PF 규칙은 변경하지 않는다. ALF는 앱 단위이므로 집 대역 제한은 기존 엔진 설정이 수행한다.

로컬 네트워크 개인정보 권한은 방화벽과 별개다. 직접 조회할 수 없는 상태를 허용으로 추정하지 않고 OS 요청·설정 위치를 안내한다. 시스템 설정 열기는 고정 OS 앱만 연다. [Apple 방화벽 안내](https://support.apple.com/en-ie/guide/mac-help/mh34041/mac), [로컬 네트워크 개인정보 보호](https://developer.apple.com/documentation/technotes/tn3179-understanding-local-network-privacy)를 따른다.

## Windows

Windows는 같은 DTO로 프로필을 조회하며 선택 연결의 고유 네트워크 ID·주소·대역을 검증한다. 명시적인 집 연결 확인 후 개인 프로필로 전환하고 필요한 UAC 승인을 요청한다. 별도 고정 Rust 도우미가 현재 사용자 전용 파이프의 양쪽 프로세스 ID와 요청 만료·원래 프로필·범위를 재검증한다. FTA 엔진·개인 프로필·선택 연결·집 대역에 한정한 TCP 규칙과 선택적인 UDP 5353 규칙을 관리하며, mDNS 멀티캐스트 수신 주소도 선택 인터페이스에 묶는다. 중복 규칙·경로 변경을 처리하고 일부 적용·응답 불명확을 성공과 구분한다. 공용 허용·전역 방화벽 해제·관리자 승인 우회는 하지 않는다. 다른 계정의 관리자 자격으로 승격하는 방식은 지원하지 않으며 해당 환경에서는 시스템 설정에서 직접 구성해야 한다.
