# FTA iOS 개인정보 처리방침
시행일: 2026년 10월 30일

운영 및 문의
FTA(File Transfer Anything)는 공개 저장소 github.com/froiibn/FTA에서 관리하는 같은 LAN의 기기 사이 전송 앱입니다. 지원·개인정보 관련 문의는 https://github.com/froiibn/FTA/issues 에서 접수할 수 있습니다. 공개 문의에 파일 내용, 비밀번호, 개인키 등 비공개 정보를 첨부하지 마세요.

전송과 기기 발견
FTA는 사용자가 선택한 파일·사진·촬영 이미지·텍스트·URL을 같은 LAN의 상대 FTA 기기로 직접 전송합니다. 클라우드 전송 중계 서버, 개발자 운영 콘텐츠 수집 서버, 광고·사용 분석 SDK를 사용하지 않습니다. 전송 내용은 개발자에게 자동 전송되지 않습니다.

기기를 찾기 위해 앱 기기 식별자, 표시 이름, 운영체제 및 연결 서비스 정보를 LAN에 알립니다. 이 발견 정보는 같은 네트워크의 다른 기기에서 확인할 수 있습니다. 최초 전송은 수신자가 한 번 기기 등록을 허용해야 하며, 허용 전에는 파일명이나 메시지 본문을 전송하지 않습니다. 등록 뒤에는 해당 기기가 온라인일 때 추가 수신 승인 없이 파일·텍스트·URL을 받을 수 있습니다. 설정에서 등록을 해제할 수 있습니다.

사진·카메라·파일 권한
사진은 시스템 사진 선택기에서 사용자가 선택한 항목만 가져옵니다. 전체 사진 보관함을 열람하거나 분석하지 않습니다. 촬영은 사용자가 요청하고 카메라 권한을 허용한 경우에만 실행하며 촬영 결과를 사진 보관함에 자동 저장하지 않습니다. 파일 앱에서는 사용자가 선택한 파일에만 접근하여 전송용 사본을 준비합니다. 선택한 사진 원본에 촬영 위치 등 메타데이터가 들어 있으면 파일과 함께 상대 기기로 전달될 수 있습니다.

로컬 네트워크 권한은 같은 LAN의 기기 발견과 송수신에 사용합니다. 신뢰한 연결은 표시된 인터페이스·허용 대역을 기준으로 기억하며, Wi-Fi 이름이나 공유기 신원을 검증하는 기능은 아닙니다. 앱이 백그라운드로 이동하거나 화면이 잠기면 송수신을 중지합니다. 알림을 허용하면 수신 결과 알림을 요청하며, 알림을 거절해도 기록에서 결과를 볼 수 있습니다.

기기 내부 저장과 보안
등록한 상대 기기의 정보, 전송 기록, 메시지 본문, 설정과 전송용 사본은 앱 저장소에 보관합니다. 최종 수신 파일은 파일 앱의 ‘나의 iPhone / FTA / 받은 파일’에 저장합니다. 실제 표시 이름은 기기 종류에 따라 다를 수 있습니다. 네트워크 전송은 TLS로 보호하며 상대의 등록된 키를 확인합니다. 개인키는 이 기기에서만 사용하는 잠금 해제 시 접근 가능한 Keychain 항목으로 보관하고, TLS 처리 중에는 앱 메모리에서 사용합니다.

비공개 엔진 상태 폴더(등록 정보·기록·엔진 설정·전송용 사본)는 자동 백업에서 제외합니다. 최종 수신 파일과 일부 iOS 앱 설정은 사용자의 OS 백업 설정에 따라 백업될 수 있습니다. 수신한 파일·URL은 자동 실행하지 않습니다. 미리보기, 공유, 복사, 링크 열기는 사용자가 선택합니다.

보관과 삭제
전송 기록은 앱에서 삭제할 수 있으며 기록을 삭제해도 이미 받은 파일은 삭제하지 않습니다. 완료·부분 완료·실패·취소로 종료된 기록은 앱의 정리 작업에서 30일, 최대 10,000건, 메시지 본문 합계 100MiB 기준에 따라 오래된 기록부터 자동 삭제될 수 있습니다. 진행 중이거나 결과가 불명확한 기록은 이 자동 정리에서 보호합니다. 받은 파일은 파일 앱에서 삭제·이동할 수 있습니다. 전송용 사본은 전송 완료, 선택 교체·해제 또는 다음 앱 시작 시 정리합니다. 실패한 전송의 사본은 다시 시도할 수 있도록 일시적으로 남을 수 있습니다. 앱을 삭제하면 앱 저장소의 파일과 기록이 삭제되지만 상대에게 이미 전달한 내용과 OS 백업은 별도로 관리해야 합니다. iOS의 Keychain 항목은 앱 삭제 후에도 남을 수 있으며, 새 앱 설치가 과거 상대 기기의 등록 승인을 자동으로 대신하지는 않습니다.

외부 서비스와 사용자 선택
지원 링크는 GitHub로 열리며 GitHub의 개인정보 처리방침이 적용됩니다. 수신한 URL을 직접 열거나 파일을 다른 앱으로 공유한 뒤의 처리는 해당 웹사이트·앱의 정책을 따릅니다. 이러한 외부 서비스에는 사용자가 해당 기능을 선택한 경우에 접속합니다.

정책 변경
개인정보 처리 방식이 바뀌면 이 문서를 갱신합니다. 앱과 공개 정책 문서는 동일한 실제 동작을 설명하도록 관리합니다.
