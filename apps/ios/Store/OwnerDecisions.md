# 소유자 결정과 제출 준비 상태

2026-11-01 현재 실제 심사 제출·출시는 하지 않았다. 사용자 결정과 기술/계정 상태를 구분한다.

1. **완료 — 스토어 앱명**: `FTA - File Transfer Anything`을 10개 로케일에 저장·재접속 확인했다. 앱 안의 FTA 이름·아이콘·bundle ID/SKU는 바꾸지 않았다.
2. **완료 — 빌드 10**: 최종 Apple Distribution/App Store IPA의 엄격한 로컬 검증, Organizer 업로드, Apple 서버 처리와 문서 누락 해소를 확인했다. 버전 0.1.2에서 빌드 10을 저장·재접속 검증했다. GUI 계정 정상에도 CLI No Accounts/이전 프로파일 불일치로 실패한 이력은 GUI 자동 서명으로 해결했으며 단순 미로그인으로 단정하지 않는다. 빌드 9는 업로드 이력으로 보존한다.
3. **완료 — 저작권**: 소유자가 `SEIZIA`로 명시 결정하여 `2026 SEIZIA`를 저장·재접속 확인했다.
4. **완료 — App Privacy 게시**: 실제 코드와 [Apple 수집 정의](https://developer.apple.com/app-store/app-privacy-details/)에 따른 수집 없음 답변이다. 소유자가 정확성·법 준수·향후 갱신 동의를 포함한 최종 게시를 승인했다. 실제 게시 후 재접속해 ‘게시함’과 수집 없음 표시를 확인했다.
5. **완료 — 콘텐츠 권한**: 앱에는 개발자가 제공하는 콘텐츠 피드/서버가 없고 사용자 선택 자료를 개인 LAN으로 전송한다. 소유자가 ‘아니요 — 타사 콘텐츠를 표시하거나 액세스하지 않습니다’를 명시 선택했으며 실제 저장/재접속 확인했다. 이 결정은 모든 사용자 자료의 저작권을 소유한다고 대신 진술한 것이 아니다.
6. **완료 — 암호화 문서면제의 소유자 선언**: 실제 Rustls/ring TLS 1.3 HTTPS와 국가 선택을 유지했다. 소유자가 [면제 재검토](ExportComplianceReview.md)를 읽은 뒤 문서 제출 면제를 명시 결정해 빌드 10의 `ITSAppUsesNonExemptEncryption=false`에 반영했다. 배포 IPA와 서버의 문서 누락 해소를 확인했지만 정부가 개별 법적 면제를 확인했다는 뜻은 아니다. [문의 초안](ExportComplianceQuestions.en.md)은 발송하지 않았다.
7. **중국 본토 — 현재 UI 차단 없음 / 개별 법적 적용은 미확정**: 175개 국가 모두 ‘앱 출시 후 사용 가능’이며 중국도 동일하고 ICP 누락 상태는 표시되지 않는다. ICP 필드는 빈칸이며 [Apple 안내](https://developer.apple.com/help/app-store-connect/reference/app-information/app-information)의 일부 앱/해당 시 요구와 구분한다. LAN 전송 앱을 뉴스·종교·출판·게임 서비스로 취급하거나 모든 앱에 ICP가 필수라고 단정하지 않는다. 번호를 만들거나 국가를 제외하지 않았다.
8. **완료 — 제출 초안 준비**: Apple 필수정보 서버검증 후 `Ready for Review` 초안 1개에 `iOS 0.1.2 (10)` 하나만 포함돼 있다. 재접속 확인했다. 별도 최종 버튼 ‘심사를 위해 제출’은 누르지 않았고 실제 심사/출시 승인으로 확대하지 않는다.

기존 무료/유료 계약 및 DSA 규정 준수는 활성 상태다. 심사 연락처 필수 값은 App Store Connect 안에서 확인하며 이 문서에는 개인 연락처, 계정 ID, 서명 키, 프로비저닝 파일이나 기기 식별자를 기록하지 않는다. 최종 실기/최소 iOS 17/Windows·Linux 재검증 공백은 계정 필수정보 누락과 구분한다.
